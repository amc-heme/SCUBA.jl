Writing a backend

Subtype AbstractSingleCellSource and implement the required methods listed in its docstring. The core never asks for whole matrices: expression(src, modality, layer, feature_idx, cell_idx) receives integer indices for exactly the block it needs. Optional methods (expression_sparse, supports_sparse, metadata_table, set_metadata!, canonical_modality, ...) have defaults. Run test_source_conformance from test/conformance.jl against a new backend.
