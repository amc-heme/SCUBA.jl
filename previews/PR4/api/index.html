API reference

Accessors

SCUBA.fetch_data — Function
fetch_data(src, vars; layer=nothing, cells=nothing, strict=false) -> DataFrame

Fetch any mix of features, metadata columns and reduction coordinates into one table with one row per cell (first column holds the cell IDs; see cell_column) and one column per found variable, in input order.

  • Features are addressed as key_feature (RNA_GAPDH, X_GAPDH, protein_CD9-AB) or, for the main modality, by bare name.
  • Reduction coordinates are addressed as reduction_dim (UMAP_1, X_umap_2).
  • Metadata columns are addressed by name, or as obs_name.

layer selects the matrix within each modality (default: default_layer). cells subsets and orders the rows. With strict=false (default) missing variables produce a warning; with strict=true they raise VarsNotFound. eltype is the element type of the expression columns (Float64 default; Float32 halves the memory of large results). With sparse=true expression columns are SparseVectors (metadata and reductions stay dense) and the dense-size guard does not apply; see also eachchunk for very wide results.

source
SCUBA.fetch_feature — Function
fetch_feature(src, features; modality=nothing, layer=nothing, cells=nothing) -> DataFrame

Fetch expression features. Bare names are looked up in modality (default: the main modality); names prefixed with a modality's key (ab_CD34) come from that modality, so one call may span several modalities. Columns keep the requested names. Unlike fetch_data, metadata and reductions are not searched.

source
SCUBA.fetch_matrix — Function
fetch_matrix(src, features; modality=nothing, layer=nothing, cells=nothing, sparse=false)
    -> (X, cells, features)

Expression block (cells × features) as a plain Matrix{eltype} or, with sparse=true, a SparseMatrixCSC{eltype}. Intended for statistics-heavy consumers (dot plots, heatmaps). features === nothing selects every feature of the modality. Dense results are subject to the MAX_DENSE_BYTES guard; sparse results are not.

SCUBA.eachchunk — Function
eachchunk(src, vars; layer=nothing, cells=nothing, strict=false, eltype=Float64, sparse=false,
          cells_per_chunk=nothing, chunk_bytes=CHUNK_BYTES[]) -> iterator of DataFrames

Iterate the result of fetch_data(src, vars; ...) in consecutive slices of the requested cell order, so a result far wider than memory can be consumed one block at a time. Every chunk has the same columns, types and metadata as the full table, so reduce(vcat, collect(it)) equals fetch_data(src, vars; ...) (without the dense-size warning). Variables are resolved once and resolution warnings are emitted once, by this call; metadata and reduction columns are read once and sliced. The chunk size is cells_per_chunk or derived from chunk_bytes and the number of expression columns.

source
SCUBA.aggregate — Function
aggregate(src, codes, ngroups; modality=nothing, layer=nothing, cells=nothing, features=nothing,
          fun=:sum, cells_per_chunk=nothing) -> (values, n, features, cells)

Sum (fun = :sum) or average (fun = :mean) every feature of a layer over groups of cells, as needed for pseudobulk profiles. codes[k] is the 1-based group of the k-th requested cell (in cells order, or object order when cells === nothing); 0 leaves a cell out. Returns the ngroups × features Matrix{Float64} of group values, the number of cells that contributed to each group (cells absent from a MuData modality do not count, see cell_present), the feature names and the cell names. features === nothing covers every feature of the modality.

The cells × features block is never built: each backend's expression! streams into a GroupSumSink, so the memory cost is the accumulator plus the backend's own read buffer (h5ad reads are bounded by MAX_READ_ELEMENTS, BPCells decodes one chunk at a time). Backends that slice through a host process (R, Python) are read in cell chunks sized by CHUNK_BYTES (see aggregate_chunk_cells); cells_per_chunk overrides the chunk size on any backend.

SCUBA.resolve_vars — Function
resolve_vars(src, vars; layer=nothing) -> ResolveResult

Classify each var as a keyed or unkeyed feature, a reduction dimension or a metadata column, following the unified SCUBA rules:

  1. A key matches only as key_ (with the underscore); matching is exact and case-sensitive.
  2. Nested keys (X vs X_umap) are tried longest-first; the first whose remainder exists wins.
  3. Unkeyed names resolve metadata → main modality → a single alternate modality (renamed key_var with a warning); names present in several alternates are ambiguous.
  4. Duplicates are collapsed by resolved target, not by spelling.

Throws VarsNotFound when nothing resolves. Warnings are returned in the result (not emitted); fetch_data emits them.

Sources

SCUBA.AbstractSingleCellSource — Type
AbstractSingleCellSource

Supertype of every SCUBA backend. Required methods:

  • cell_ids(src), modality_keys(src), default_modality(src), default_layer(src)
  • feature_names(src, modality), layer_names(src, modality)
  • expression(src, modality, layer, feature_idx, cell_idx) → Matrix{Float64} (cells × features)
  • metadata_names(src), metadata_column(src, name, cell_idx)
  • reduction_keys(src), reduction_ndims(src, key), reduction(src, key, dims, cell_idx) → Matrix{Float64} (cells × dims)

Optional methods have defaults: supports_sparse, expression_sparse, reduction_dimnames, layer_exists, metadata_table, set_metadata!, invalidate!, cache, source_name.

MemoryAnnData(; cells, obs=DataFrame(), modalities, reductions=OrderedDict(), default_layer="X")

SCUBA.LazyMatrix — Type
LazyMatrix

A matrix-like layer whose values live elsewhere (disk, another process). Implement Base.size(m) -> (ncells, nfeatures) and pull(m, feature_idx, cell_idx) -> Matrix{Float64} (cells × features); optionally pull_sparse.

source
SCUBA.H5ADSource — Type
H5ADSource(path) / open_h5ad(path)

Lazily read an .h5ad file. Only the schema (names, encodings, shapes) is read at open time; expression values are read on demand, one coalesced hyperslab per block. Modalities: "X" (layers "X" plus every layers/*), every obsm data frame (e.g. protein), and raw if present. Reductions: every numeric obsm array (e.g. X_umap). Close with close(src).

source
SCUBA.BPCellsMatrix — Type
BPCellsMatrix(dir) / open_bpcells(dir)

Lazy layer over a BPCells matrix directory. As a LazyMatrix it presents the cells × features orientation expected by SCUBA (size(m) == (ncells, nfeatures)), while row_names(m) / col_names(m) give the stored feature and cell names. Decoded index chunks are cached.

Sinks

Every backend writes expression values through SCUBA._put!(sink, i, j, v); the sink decides what to keep. A dense matrix or a vector of per-feature columns keeps everything, SparseSink keeps the nonzeros, and GroupSumSink keeps only group sums.

SCUBA.SparseSink — Type
SparseSink(T, nfeat)

Sparse output sink: one (I, V) buffer per feature column, filled through _put!. Explicit zeros are dropped, so dense-backed layers yield genuinely sparse results and sparse and dense results agree on values. Convert with to_sparse_matrix / to_sparse_columns.

source
SCUBA.RowMapSink — Type
RowMapSink(inner, rows)

Sink adaptor mapping the row (cell) position i of the writer to rows[i] in inner; used when a modality holds only a subset of the cells (MuData).

source
SCUBA.GroupSumSink — Type
GroupSumSink(T, codes, ngroups, nfeat)

Reduction sink for aggregate: _put!(s, i, j, v) adds v to acc[codes[i], j], where codes[i] is the 1-based group of the cell at position i of the request being written (0 skips the cell). The cells × features block is never materialised: every backend's expression! streams straight into the ngroups × nfeat accumulator, which is all the memory a pseudobulk profile needs. GroupSumSink{T}(acc, codes) wraps an existing accumulator so a request can be written in several cell chunks (each with its own slice of codes).

SCUBA.expression! — Function
expression!(out, src, modality, layer, feature_idx, cell_idx) -> out

Write every value of the requested block into out through _put!(out, i, j, v) (cell position i, feature position j). out is a Matrix{T}, a Vector{Vector{T}} (per-feature columns) or a SparseSink. Backends implement this one method to get typed dense, column and sparse results; the default materialises expression and scatters it.

SCUBA.aggregate_chunk_cells — Function
aggregate_chunk_cells(src, modality, layer, nfeat) -> Union{Nothing,Int}

Cells per chunk that aggregate should request at a time from this backend, or nothing (default) to stream the whole request through one expression! call. Backends that materialise every slice through a host process (the R and Python bridges) return a chunk size derived from CHUNK_BYTES so the slice never exceeds that budget.
